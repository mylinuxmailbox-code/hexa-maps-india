# HEXA MAPS

> **Open maps. Smarter navigation. Community-powered traffic.**

HEXA MAPS is a multi-platform, 2D-first, privacy-preserving, self-hostable open-source mapping, navigation, and live traffic ecosystem.

## Release Sequence
1. **Phase 1:** macOS
2. **Phase 2:** iOS
3. **Phase 3:** Android
4. **Phase 4:** Self-hostable Web
