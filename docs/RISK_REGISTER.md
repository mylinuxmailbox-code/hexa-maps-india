# HEXA MAPS — Technical & Operational Risk Register

**Last Updated:** 2026-11-13

| ID | Risk Category | Description | Likelihood | Impact | Mitigation Strategy | Owner Gate |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **R-01** | **macOS Map Rendering** | MapLibre Native's macOS AppKit target (`MLNMapView`) is documented upstream as primarily for core development/testing, lacks prebuilt Swift Package Manager binaries for macOS desktop, and has unmaintained AppKit UI glue. | High | High | Execute [MACOS_RENDERER_SPIKE.md](file:///Users/vihaang/.gemini/antigravity/scratch/hexa-maps/docs/MACOS_RENDERER_SPIKE.md) in Gate 1 comparing a custom CMake build of MapLibre Native macOS vs. MapLibre GL JS v6.18 inside `WKWebView` with native SwiftUI overlays and local `WKURLSchemeHandler` tile streaming. Keep renderer behind a Swift `MapCanvasProtocol`. | Gate 1 |
| **R-02** | **Valhalla Graph vs. Traffic ID Mismatch** | Valhalla's internal `GraphId` (level, tile_id, edge_id) changes whenever `valhalla_build_tiles` runs on a new OSM extract. Applying a `traffic.tar` built for Graph A onto Graph B corrupts speeds or crashes routing. | High | Critical | Stamp every Valhalla tile bundle with a cryptographic `graph_version_id`. Reject any `traffic.tar` whose header/manifest `graph_version_id` does not match the active graph. Never assume OpenTraffic OSMLR IDs map 1:1 without a graph-version lookup table. | Gate 1 / Gate 5 |
| **R-03** | **Traffic Cold-Start & Dishonest UI** | A newly deployed instance or low-traffic road has zero or $<5$ community probes. Showing green lines implies "free-flowing traffic" when the system actually has no data, misleading drivers. | High | High | Enforce strict 6-state traffic classification (`LIVE`, `LIVE_LOW_CONFIDENCE`, `HISTORICAL`, `ESTIMATED`, `STALE`, `NO_DATA`). Render `NO_DATA` with neutral road styling and explicit UI indicator—never green. | Gate 5 |
| **R-04** | **Traffic Spoofing & Sybil Congestion Attacks** | Malicious actors simulate 100 virtual devices walking/stopped on a highway (analogous to the 99-phones-in-a-wagon attack) to trigger fake congestion and divert real traffic onto residential streets. | Medium | High | Implement multi-factor probe validation: kinematics feasibility, map-matching residual bounds, contributor trust scoring, rate-limiting per ephemeral token/IP subnet, and outlier damping when a sudden cluster of unverified tokens appears on a single edge without upstream/downstream shockwave propagation. | Gate 5 / Gate 6 |
| **R-05** | **Contributor Re-Identification on Low-Density Roads** | Publishing live speeds or probe traces on a quiet suburban cul-de-sac reveals when a single resident leaves or returns home. | High | Critical | Hard privacy gates: (1) Strip first/last 500m + random 100–300m jitter from every trip on-device and at ingestion; (2) Rotate ephemeral session tokens every 15 minutes; (3) Enforce $k$-anonymity ($k \ge 5$ distinct sessions within a 15-minute window) before publishing `LIVE` speeds on any edge; (4) Never log raw GPS coordinates. | Gate 6 |
| **R-06** | **ODbL Share-Alike & Licence Contamination** | Merging proprietary business data, scraped datasets, or restrictively licensed third-party POIs into the same PostGIS table or vector tile layer as OpenStreetMap data violates ODbL or triggers unintended copyleft obligations. | Medium | Critical | Enforce strict Horizontal Layer Separation (see `DATA_PROVENANCE_REGISTER.md`). Keep OSM-derived data, HEXA Community contributions, and external enrichment providers in distinct schemas/layers joined at query/render time with per-field source attribution. | Gate 0 / Continuous |
| **R-07** | **MinIO Upstream Deprecation (S3 Storage)** | MinIO archived its open-source community edition and stopped publishing official community Docker images in 2025–2026, shifting to commercial AIStor. | Confirmed | Medium | Replace MinIO with **SeaweedFS** (Apache-2.0) or **Garage** (AGPLv3) behind a standard AWS S3 SDK v3 interface (`S3StorageProvider`). | Gate 0 (Resolved) |
| **R-08** | **Country Highway Shield Inaccuracy & Trademark Nuances** | Rendering generic white pills or applying the wrong country's highway shield degrades cartographic trust; conversely, copying copyrighted proprietary sprite sheets or restricted royal crests creates legal exposure. | Medium | Medium | Build `packages/highway-shields` using CC0 `@americana/maplibre-shield-generator` definitions + clean geometric SVG badges verified against official national sign manuals (IRC India, US MUTCD, UK TSRGD, DE StVO). Fallback to neutral rounded badge for unknown `network` tags. | Gate 1 / Gate 2 |
| **R-09** | **Public Transit Realtime Feed Gaps (Bengaluru Pilot)** | While BMTC and BMRCL static schedules are accessible via community/MobilityData GTFS, public unauthenticated GTFS-Realtime feeds in Bengaluru have registration/availability constraints via IUDX. | High | Medium | Ship OpenTripPlanner with verified static GTFS first; clearly label schedules as `Scheduled` vs `Live` in UI; treat GTFS-RT vehicle positions as a pluggable adapter enabled only when an operator configures valid agency/IUDX credentials. | Gate 8 |
| **R-10** | **Offline Package Corruption & Disk Exhaustion** | Partial downloads of multi-hundred-megabyte `.pmtiles` and Valhalla routing tarballs over unstable mobile/Wi-Fi connections can corrupt local state. | Medium | Medium | Use atomic staging directories, HTTP `Range` resumable downloads, per-chunk + full-archive SHA-256 verification against signed region manifests, and automatic rollback to the previous valid version on checksum failure. | Gate 2 / Gate 4 |
